# Student Sorter

**Русский** · [English](README.en.md)

[![CI](https://github.com/EDeev/student_sorter/actions/workflows/ci.yml/badge.svg)](https://github.com/EDeev/student_sorter/actions/workflows/ci.yml)

Учебное Windows-приложение для приёмной комиссии: ведёт список абитуриентов, сортирует и фильтрует его,
строит рейтинг направлений и формирует список иногородних, которым нужно общежитие.

**Статус:** учебный проект (РГРТУ, 2024), завершён

**Стек:** C++/CLI · Windows Forms (.NET Framework 4.8) · Visual Studio 2022 (MSVC v143) · библиотека курса RSREU.IO

## Возможности

- Добавление абитуриента: ФИО, адрес, льгота, баллы ЕГЭ, направление подготовки
- Таблица абитуриентов с сортировкой по столбцам и фильтром по направлению подготовки
- Рейтинг направлений по популярности, соотношение местных и иногородних
- Диаграмма: доля абитуриентов с льготами
- Список на общежитие: все, кто прописан не в Рязани, — в `stud.txt` (формат — [examples/stud.txt](examples/stud.txt), ФИО вымышленные)
- Список хранится между запусками в `applis.dat`

## Сборка

1. Откройте `InvestWinApp.sln` в Visual Studio 2022 с компонентом «Поддержка C++/CLI».
2. Положите библиотеку курса `RSREU.IO.dll` в `InvestWinApp/x64/Debug/` (её в репозитории нет — она
   выдавалась на курсе).
3. Соберите конфигурацию x64.

> [!NOTE]
> Без `RSREU.IO.dll` проект не собирается, поэтому CI проверяет только кодировку исходников (UTF-8).
> Решение называется `InvestWinApp` — так проект был создан в Visual Studio.

## Структура

```
InvestWinApp/
├── InvestWinApp.cpp    точка входа, запись списка в файл
├── config.h            структура Applicant
├── MyForm.h            главная форма: таблица, сортировка, рейтинг направлений, диаграмма, список на общежитие
└── AddApplicant.h      форма добавления абитуриента
Data/                   иконки
Пояснительная записка.pdf
```
